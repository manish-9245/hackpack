# hackpack Product Brief

## What is hackpack?

A CLI tool that scaffolds full-stack hackathon projects in seconds. Users pick a framework/language, select features (UI, auth, DB, AI), and get a wired, deployable app—zero boilerplate, zero LLM randomness.

## Target Audience

- Hackathon participants (primary): Need to ship fast, not debate stack choices
- Startup founders: Need an MVP scaffold that's type-safe and extensible
- Full-stack learners: Want to understand how auth, DB, and APIs wire together

## Core Value Propositions

1. **Speed**: Full-stack project in 90 seconds. No onboarding tax.
2. **Composability**: Pick any base + feature combo. No unexpected side effects.
3. **Determinism**: Same input = same output. No LLM randomness. Perfect for reproducible hackathons.
4. **Type-Safety**: Zod, Drizzle, TypeScript by default. Catch bugs at compile time.
5. **Portable**: Export to git. No vendor lock-in. Deploy to Workers, Docker, or anywhere.

## Competitive Differentiation

- vs. Create React App / Next.js templates: Composable across frameworks + languages, better feature selection
- vs. Firebase / Supabase: Self-contained, local-first, no cloud vendor required, faster iteration
- vs. LLM code generators (Cursor, etc.): Deterministic, reproducible, auditable—ideal for teams

## Tone

- **Direct, confident, slightly irreverent**: "No boilerplate. No debates. Just ship."
- **Outcome-focused, not feature-dumping**: Show what you *build*, not what we *have*
- **For builders**: "Make stuff faster" resonates more than "framework support"

## Visual Identity

- **Color meaning**: Blue = speed/action, Green = ready-to-deploy, Pink = AI/power, Purple = composability
- **Typography**: Bold, confident headlines. Tight, benefit-forward body copy.
- **Motion**: Subtle reveals, animated stats, fast transitions. Conveys speed.
- **Code visibility**: Real project snippets, not generic examples.

## Success Metrics (for landing page)

- CTR on "Get Started" / "Try Now"
- Time on page (should be <2min; we're convincing, not exhausting)
- Scroll depth to examples/CTA
- GitHub link clicks (social proof)
